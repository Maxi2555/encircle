# Security policy

Encircle sees everything on your screen when you invoke it, so security and privacy problems are taken seriously.

## Supported versions

Only the latest release receives fixes. Please check that the problem still exists there before reporting.

## Reporting a vulnerability

**Do not open a public issue.** Report privately through GitHub instead:

1. Go to the [Security tab](https://github.com/Maxi2555/encircle/security) of this repository.
2. Click **Report a vulnerability** and describe the problem, the affected version and how to reproduce it.

You will get a first answer within two weeks. Once a fix is released, the advisory is published and you are credited unless you prefer otherwise.

## In scope

- Screen content, selections or screenshots leaving the device or becoming readable by other apps.
- Other apps triggering Encircle's actions or reading its files without user interaction.
- Encircle performing actions (opening links, joining Wi-Fi networks, dialling) without the user choosing them.
- Crafted QR codes or on-screen text that crash the app or make it misbehave.

## Out of scope

- Behaviour of the Android assistant framework itself, or of the operating system.
- Issues that require a rooted or otherwise compromised device.
